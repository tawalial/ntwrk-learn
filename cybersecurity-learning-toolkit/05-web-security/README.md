# Dasar Web Security

Urutan materi:
1. Cara kerja browser, server, request, dan response.
2. HTTP methods, status code, headers, cookies, dan session.
3. HTTPS dan sertifikat TLS.
4. Validasi input dan output encoding.
5. Authentication dan authorization.
6. OWASP Top 10 sebagai peta konsep risiko web.

Latihan hanya pada aplikasi lokal atau lab yang memberi izin. Jangan menguji situs publik atau akun orang lain.
