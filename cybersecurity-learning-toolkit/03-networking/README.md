# Dasar networking

Pelajari konsep berikut sebelum menggunakan alat:
1. IPv4 dan IPv6
2. MAC address dan ARP
3. TCP, UDP, dan port
4. DNS
5. HTTP dan HTTPS
6. Routing, gateway, dan subnet

Catat istilah baru dengan contoh sederhana. Jangan melakukan pengujian ke jaringan yang bukan milik sendiri atau tanpa izin.
