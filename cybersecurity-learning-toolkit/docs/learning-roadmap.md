# Roadmap belajar bertahap

## Tahap 1 — Fondasi
- Navigasi Linux dan Windows Terminal.
- File, permission, proses, package manager.
- Python dasar dan Git.

## Tahap 2 — Networking
- IP, subnet, gateway, DNS.
- TCP/UDP, port, HTTP/HTTPS.
- Membaca konfigurasi jaringan lokal.

## Tahap 3 — Analisis
- Wireshark dan tcpdump pada trafik milik sendiri.
- Nmap pada loopback atau lab berizin.
- Membuat catatan hasil dan memahami mitigasi.

## Tahap 4 — Web security
- Dasar web dan autentikasi.
- OWASP Top 10.
- OWASP ZAP pada aplikasi lab lokal.

## Tahap 5 — Portofolio
- Dokumentasi tiap latihan.
- Script Python kecil yang aman.
- Laporan temuan lab beserta rekomendasi perbaikan.

Belajar pelan-pelan. Pahami konsep sebelum mencoba alat.
