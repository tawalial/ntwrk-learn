# Python untuk belajar keamanan

Jalankan contoh dari root repository setelah mengaktifkan virtual environment:

```bash
python 02-python/examples/system_info.py
python 02-python/examples/file_hash.py README.md
```

- `system_info.py`: menampilkan informasi Python dan OS lokal.
- `file_hash.py`: menghitung SHA-256 file lokal untuk memeriksa integritas.

Gunakan virtual environment agar pustaka proyek terpisah dari Python sistem.
