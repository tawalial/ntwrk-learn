# Lab praktik aman

Mulai dari:
- Komputer Ubuntu milik sendiri.
- Aplikasi demo yang sengaja dibuat rentan dan dijalankan lokal.
- Materi latihan resmi yang secara eksplisit mengizinkan pengujian.

Catat setiap latihan:
1. Tujuan pembelajaran.
2. Sistem/lab yang digunakan dan bukti izin.
3. Langkah yang dilakukan.
4. Hasil pengamatan.
5. Pelajaran dan cara mitigasi.

Jangan menguji jaringan kampus, kantor, Wi-Fi umum, atau sistem pihak lain tanpa izin tertulis.
