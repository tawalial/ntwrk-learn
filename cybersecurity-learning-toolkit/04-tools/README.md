# Daftar tools

| Tool | Kegunaan belajar | Catatan |
|---|---|---|
| Nmap | Memahami host dan layanan pada lab berizin | Mulai dari loopback sendiri |
| Wireshark | Mempelajari paket dan protokol | Tangkap trafik milik sendiri |
| tcpdump | Pengamatan paket lewat terminal | Gunakan interface dan lab sendiri |
| dig | Memahami DNS | Mulai dengan domain latihan atau milik sendiri |
| WHOIS | Informasi registrasi domain publik | Pahami batas dan privasi data |
| Git | Riwayat perubahan kode | Jangan commit secret |
| Python | Otomasi dan analisis lokal | Gunakan virtual environment |
| OWASP ZAP | Belajar pengujian keamanan web | Gunakan aplikasi lab lokal yang sengaja dibuat untuk latihan |

OWASP ZAP tidak dipasang otomatis oleh installer. Ikuti dokumentasi resmi proyek untuk metode instalasi terbaru.
