# Cybersecurity Learning Toolkit
Perpustakaan belajar cybersecurity berdasarkan tujuan folder: instalasi, Python, networking, tools, web security, lab practice, cryptography, digital forensics, dan laporan.

## Mulai
Ubuntu:
```bash
cd 01-installation/ubuntu
chmod +x install.sh
./install.sh
```
Windows PowerShell:
```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\install.ps1
```
Semua pengujian hanya pada perangkat atau lab yang kamu miliki atau yang memberi izin eksplisit. Jangan unggah password, token, private key, atau data pribadi.
