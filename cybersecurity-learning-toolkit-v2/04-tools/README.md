# 04 — Tools
Tujuan: mengenal alat keamanan dan batas penggunaannya.
- Nmap: memahami host dan layanan pada lab berizin.
- Wireshark: mempelajari paket jaringan milik sendiri.
- tcpdump: pengamatan paket lewat terminal.
- dig: memahami DNS.
- WHOIS: informasi registrasi domain publik.
- OWASP ZAP: belajar pengujian aplikasi web pada lab lokal.
OWASP ZAP tidak dipasang otomatis. Jangan menguji target tanpa izin.
