# 07 — Cryptography
Tujuan: memahami hash, enkripsi, dan tanda tangan digital.
- Hash: sidik jari data untuk memeriksa integritas.
- Enkripsi: menjaga kerahasiaan dengan kunci.
- Tanda tangan digital: membantu memeriksa keaslian dan integritas.
- Encoding bukan enkripsi.
Contoh hash file lokal: `sha256sum README.md`.
