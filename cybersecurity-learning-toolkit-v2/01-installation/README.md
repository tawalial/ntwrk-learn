# 01 — Installation
Tujuan: menyiapkan perangkat belajar.
- `ubuntu/install.sh`: memasang Python, Git, Nmap, Wireshark, tcpdump, dan utilitas jaringan.
- `windows/install.ps1`: memasang Python, Git, VS Code, Nmap, Wireshark.
- `requirements.txt`: library Python.
Baca script sebelum menjalankannya. Installer hanya memasang paket.
