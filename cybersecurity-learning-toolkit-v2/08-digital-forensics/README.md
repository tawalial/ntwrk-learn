# 08 — Digital Forensics
Tujuan: mengenal pemeriksaan bukti digital secara defensif.
1. Pastikan memiliki izin atas perangkat dan data.
2. Jangan ubah bukti asli; gunakan salinan bila memungkinkan.
3. Catat waktu, sumber, langkah, dan hasil.
4. Gunakan hash untuk memeriksa integritas salinan.
5. Jaga privasi dan batasi akses data.
